# Swati Sriram — Engineering Portfolio

Static HTML/CSS/JavaScript site. Open `index.html` in a browser.

- Edit project text in `script.js`.
- Edit design and colors in `style.css`.
- Replace page screenshots in `assets/` with cropped, high-resolution project images as they become available.
- Add your current resume as `assets/resume.pdf`.
- Publish the folder through GitHub Pages, Netlify, or another static host.

The project images are screenshots of pages from the supplied PDF; they are placeholders until individual CAD renders and photos are available.
